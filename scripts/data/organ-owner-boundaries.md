| 左右肺動脈（pulmonary artery） | 肺（使用者 2026-10-31 決定） | 模型裡的左右肺動脈網格從肺門再深入肺內約 2 cm，現在跟著肺：要「動脈」與「呼吸」兩個開關都開才顯示。肺面板與肺詳細檢視會把呼吸打開，所以仍看得到 |
| 上、下肺靜脈（superior／inferior pulmonary vein） | 肺（使用者 2026-10-31 決定） | 同上，網格從肺門深入肺內，跟著肺：要「靜脈」與「呼吸」都開才顯示。肺動脈幹（pulmonary trunk）仍是經過，不隨肺隱藏 |
| 支氣管動脈、支氣管靜脈 | 肺 | 起自胸主動脈或肋間後動脈，但名稱與走向都是供應支氣管，與肺一起顯示；起始處靠近主動脈的一小段也一起隱藏 |
| 冠狀動脈起始段（trunk of coronary artery） | 心臟 | 起自主動脈竇，主動脈本身仍是經過 |
| 心包膈動脈、心包膈靜脈 | 經過 | 沿心包與膈神經走到橫膈，不是心臟的血管 |
| 肝總動脈、肝固有動脈、肝動脈幹、門靜脈、門靜脈幹、肝前門靜脈 | 經過（使用者 2026-10-31 確認，一律顯示） | 在肝十二指腸韌帶內到肝門為止，不隨消化開關隱藏；肝內的葉支、肝段支與肝靜脈歸消化 |
| 腎動脈、腎靜脈 | 經過（使用者 2026-10-31 確認，一律顯示） | 到腎門為止，不隨泌尿開關隱藏；腎竇內的節段支（superior／inferior／posterior segmental branch of renal artery 與腎前段動脈）歸泌尿 |
| 腎上腺靜脈（suprarenal vein）、睪丸動靜脈（testicular）、卵巢血管 | 經過 | 走在後腹膜與腹股溝管，長距離經過；睪丸、卵巢本體的血管模型沒有 |
| 脾動脈、脾靜脈 | 經過（使用者 2026-10-31 確認，一律顯示） | 沿胰腺走到脾門，不隨器官隱藏；模型沒有脾內分支 |
| 腸繫膜上動脈幹、腸繫膜下靜脈、腸繫膜上靜脈、腹腔動脈幹、胃十二指腸動脈幹 | 經過 | 主幹；由它們發出走向胃、腸、胰的分支（胃、胃網膜、結腸、迴腸、迴結腸、闌尾、盲腸、胰十二指腸、乙狀結腸、直腸上）歸消化 |
| 食道動脈、食道叢 | 消化 | 貼在食道壁上；它們在縱隔，所以「縱隔與心臟」預設開啟消化，仍會顯示 |
| 子宮動脈、子宮靜脈、陰莖背深／淺靜脈 | 生殖 | 只供應子宮／陰莖；陰部內動脈、陰部內靜脈等經過會陰，歸經過 |
| 腦血管（大腦、小腦、胼胝體周圍、脈絡叢、橋腦、丘腦、前後交通動脈等） | 腦（跟「神經系統」開關；使用者 2026-10-31 決定不另設「腦」開關） | 腦沒有獨立的器官開關，歸神經系統；頸內動脈、椎動脈、眼動脈、脊髓前動脈歸經過。基底動脈待使用者決定（目前：經過） |
| 睫狀神經節、睫狀神經、視神經、眼動脈 | 經過（待使用者決定） | 眼眶內容物；眼沒有跟頭頸區域預設開啟的器官開關，隨眼隱藏會讓眼眶神經消失，先不歸屬 |
| 腹腔神經節、主動脈腎神經節、腸繫膜上神經節、腎神經節 | 經過（腎神經節待使用者決定） | 前椎神經節包在主動脈旁的叢內；腎神經節在腎門附近，先歸經過 |
| 迷走神經前幹、後幹 | 經過 | 迷走神經本身；沿食道走，不是食道壁內的神經叢 |
