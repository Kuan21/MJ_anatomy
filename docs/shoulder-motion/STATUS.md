# 肩屈曲／外展 180°：進度（暫停點）

## 已做（已推到 mj-shoulder-flex，尚未開 PR）
- **紅色血管碎段**：原因有三。(1) 胸外側動／靜脈的「-END」端片段用另一套權重，與主體（纜線模型）分離；(2) 胸上動脈、乳外側動脈是示意血管，沒有綁定，留在軀幹而其母血管隨手臂移動；(3) 胸壁側的血管神經路徑權重被整條肱骨帶走。修法：`alignEndPiece`（端片段取主體權重）、`prepare-paokao.mjs` 綁定兩條胸壁分支、`pathWeights` 在離肱骨軸遠處回到軀幹。`scripts/audit-vessel-gaps.mjs` 量測相接血管在姿勢下分開的距離：胸外側動脈主體與端片段 566 mm → 約 53 mm；仍有 150–200 mm 的相接處（胸外側動脈與乳外側動脈、胸肩峰動脈胸肌支與其端片段）。
- **灰色半透明盒狀物**：是腋鞘（示意鞘，kind=sheath，以 20 % 不透明度繪製）被拉成拱形。修法：鞘只在被選取時繪出。只開「結締組織」的截圖（flex180-grey-arch-connective-only.png）可見拱形。
- **肌肉撕成條狀**：`surface-constraints.ts` 的「剛性錨點完全不動」讓求解器把自由頂點拉斷；改為錨點可動 5 %、10 次迭代，前鋸肌不再套用該限制。離線稽核：前鋸肌最大邊拉伸 8.0 倍 → 2.8 倍，大圓肌 3.2 倍 → 正常。畫面上前鋸肌指狀束仍呈長條，截圖前後差異不大。
