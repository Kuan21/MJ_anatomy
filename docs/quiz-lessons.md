# Quiz 第二級「學習關卡」：關卡產生、星星與複習規則

內部文件（只放在 `docs/`，不放進 `public/` 或 `dist/`）。程式在 `app/quiz/lessons.ts`、`lesson-progress.ts`、`lesson-mode.tsx`，測試在 `scripts/test-quiz-lessons.mjs`（已併入 `npm run check`）。

## 等級編號

| 等級 | 內容 | 錯題本鍵 |
| --- | --- | --- |
| 第一級 | 給名稱，在模型上點出結構 | `<部位>:L1` |
| 第二級 | 學習關卡（本文件） | `<部位>:L2` |
| 第三級 | 看結構，打出名稱（原本的第二級） | `<部位>:L3` |

舊版存在 `…:L2` 的錯題（當時是「打名稱」）在載入時一次性移到 `…:L3`（`migrateMistakes`，標記鍵 `mj-quiz-mistakes-migrated:L2-to-L3`）。標記先寫入，所以只會移一次；已有的 `:L3` 清單會合併而不是覆蓋；新的第二級錯題留在 `:L2`。三個等級共用同一個題庫，`scripts/check-quiz-banks.mjs` 會比對（第二級的關卡必須剛好涵蓋題庫）。

## 關卡怎麼切

由目錄資料自動產生，不需要為新部位或新類別寫程式：

1. 題庫 = 第三級的題庫（有模型、有中文名、名稱不重複），依設定頁的部位區段、左右側與範圍（摘要／延伸）篩選。
2. 依「類別」分組（骨、肌肉、肌腱、神經、動脈、靜脈、韌帶與筋膜、特殊空間與孔、器官結構），一關只有一種類別。類別勾選只決定列出哪些關卡，不會改變關卡編號。
3. 每個類別內依位置排序：由上而下（模型的 y 座標，上肢與下肢就是近端到遠端），同高度時依名稱、id，所以結果不受目錄檔順序影響。
4. 每關約 `target` 個（預設 8）：`k = round(n / target)` 關，平均分配（大小最多差 1，多的排前面）。每關 4 至 12 個；類別總數少於 4 時只有一小關（這是唯一的例外）。
5. 每個可出題的構造剛好在一關裡。
6. 關卡名稱預設為「類別 + 編號 + 該關第一個與最後一個構造所在的區段」，例如 `Muscles 3 · Thigh`／`肌肉 3・大腿`，跨區段時 `Muscles 4 · Thigh – Leg`／`肌肉 4・大腿～小腿`（區段取構造自己所屬區段中、高度範圍包含其中心的最窄一個）。

關卡的進度存在瀏覽器，鍵為 `<左右側>|<區段>|<範圍>/<類別>-<編號>`；換部位區段或左右側就是另一組關卡。

## 人工調整：`app/data/quiz-lessons/overrides.json`

```json
{
  "target": 8,
  "names": {
    "lower-limb/muscle-1": {"en": "Gluteal muscles", "zh": "臀肌"}
  },
  "pin": {
    "lower-limb/muscle": ["gluteus maximus", "gluteus medius"]
  }
}
```

- `target`：每關目標題數（建議 6 至 10）。
- `names`：鍵為 `<部位id>/<類別id>-<編號>`，覆寫該關的英文與中文名（英文在上、中文在下）。編號是預設設定（部位區段全部、右側或雙側）下的編號；換了區段或左右側，關卡內容不同，名稱仍會套用到同編號的關。
- `pin`：鍵為 `<部位id>/<類別id>`，列出的構造名稱（不含 Left／Right，大小寫不拘）移到該類別最前面，依列出順序排；沒列出的維持由上而下。不會增減構造。
- 部位 id：`lower-limb`、`upper-limb`、`thorax`、`back`、`heart`、`lung`；類別 id：`bone`、`muscle`、`tendon`、`nerve`、`artery`、`vein`、`ligament`、`space`、`organ`。
- 改完請跑 `node scripts/test-quiz-lessons.mjs`。

## 三輪

同一關的同一批構造練三輪：

1. 第一輪「學習」：構造用黃色標示，名稱直接顯示，輸入一次幫助記憶（英文或中文皆可，打錯可再試，不計分；可略過）。
2. 第二輪「提示」：黃色標示，名稱隱藏，顯示提示：英文名每個字的第一個字母、中文名、一行位置說明。位置說明只取資料卡已有的欄位，依序找「位置」「起點」「來源」「主要標誌」「走向與通道」「走向」，取第一句（最多 46 字）；沒有這些欄位就不顯示這一行，不編造；如果該句包含構造自己的名稱（會洩漏答案）也不顯示。作答語言選「中文」時，中文名只顯示第一個字與字數。
3. 第三輪「憑記憶」：沒有提示，視角與第一、二輪不同（見下）。

第二、三輪用第三級的判分（`naming.ts` 與同義詞表）：接近的答案會顯示正確拼法並列入錯題。答錯（含接近、我不知道）後顯示正確名稱與資料卡，再下一題；該輪答錯的構造會在該輪結尾再出現一次（只一次，重出現的不計分）。

### 視角

第一、二輪的視角由「部位 + 構造 id」當種子決定（同一構造每次相同）；第三輪另用一個種子，並排除與第一輪視角夾角小於 60 度的方向（`dot > 0.5`），所以一定看到另一個方向（仍要求目標至少一半可見）。「題目視角」按鈕回到該輪的起始視角。

## 星星

以第三輪「一次答對」（第一次作答就正確）的比例 `a`，以及第二、三輪「第一次作答不正確」的次數 `W`（答錯、接近、我不知道都算）：

| 星星 | 條件 |
| --- | --- |
| ★★★ | `a = 100%` 且 `W ≤ 2` |
| ★★ | `a ≥ 80%` |
| ★ | `a ≥ 50%`（這一關算「已通過」） |
| 0 | `a < 50%` |

第二輪一律顯示提示，所以「提示用量」不另外計，改以第二輪的答錯次數反映。一關的星星記最佳成績（之後較差的成績不會扣星）。常數在 `STAR_RULES`（`lesson-progress.ts`）。

關卡列表的摘要格式：`N 關 · 已通過 M · ★ x/y`（`y = 3N`）。

## 打字速度與正確率

結果頁顯示小字：`打字速度 N WPM · 不看答案的正確率 X%`。

- WPM：每 5 個拉丁字元算 1 字，每個中文字算 1 字；時間是每題「按下第一個鍵」到「送出」的毫秒，只計第一次作答，三輪合計。總時間不足 1 秒不顯示。
- 正確率：第二、三輪第一次作答中答對的比例。

## 間隔複習

以每個區域各自存在瀏覽器（`mj-quiz-review:<部位>`，內容 `{構造id: {stage, due}}`）。

- 第三輪（與「今日複習」、錯題練習）的第一次作答才更新排程。
- 答對：沒有紀錄就排 1 天後；到期日當天或之後答對，依序前進 1、3、7、14、30 天（最後一階重複 30 天），間隔從複習當天算起；還沒到期就答對，不改變。
- 答錯：回到 1 天後（階段 0）。
- 「今日複習」列出到期（到期日 ≤ 今天）的構造，最久的優先，並以混合的第三輪進行。
- 日期邏輯在純函式（`applyReview`、`dueIds`、`addDays`，都可傳入 `today`），日期用本機時區的 `YYYY-MM-DD`。
- 所有 localStorage 讀寫都包在 try/catch；沒有儲存空間時功能照常，只是進度不保留。
