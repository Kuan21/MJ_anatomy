# Quiz：腹部、骨盆與會陰

Quiz、學習關卡與模擬考試的「腹部」區域（`#/quiz/abdomen`，骨盆與會陰區域隨後以同一做法加入）。第一級（點出位置）、第三級（寫出名稱）、學習關卡與模擬考試共用同一份題庫 `public/models/quiz-abdomen.json`，由 `scripts/prepare-quiz.mjs` 產生，規則在 `app/quiz/trunk.ts`，名稱比對在 `scripts/lib/trunk-quiz-source.mjs`。

## 題庫範圍

- 來源是主站在腹部已有的構造：圖譜（BodyParts3D）、補充構造、課程整理包裡的神經節與內臟神經、腹壁神經疊層。區域歸屬用主站頂部區域列同一套規則（`app/mj-region-bar.ts`），所以題庫與主站「腹腔」分頁看到的是同一批構造。
- 不出題並逐項記錄原因的有：肝實質與肝節段、膽道樹、胰實質與胰管樹、腎動脈的節段分支、肝動脈與門靜脈的肝內分支與屬支（器官內部構造，由各器官詳細模式的 Quiz 出題）；降主動脈、胸導管、膈上血管、闊背肌（屬胸腔或背部的 Quiz）；同名無法分辨者。清單在 `docs/quiz-trunk-pool.md`。
- 模型有兩個名稱的同一構造合併成一個題目（腹腔動脈幹與 Celiac trunk、腎動脈與其主幹、空腸與迴腸的三段合為整個器官等，見 `TRUNK_MERGE`）。
- 左、右是構造本身名稱一部分的（左胃動脈、右結腸靜脈、左肝管等）當作沒有左右的構造，不因選擇左側或右側而被排除。

## 區段與類別

區段（每個構造一個）：腹壁與腹股溝、胃腸與腹膜、肝膽胰脾、腎與腎上腺與後腹壁、腹部血管、腹部神經與神經叢、腰椎肋骨與骨盆骨。類別（與其他區域相同，可自由組合）：骨、肌肉、神經、動脈、靜脈、韌帶與筋膜、特殊空間與孔、器官結構。腹白線、腹股溝韌帶、腹直肌鞘、繫膜與帶歸「韌帶與筋膜」，主動脈裂孔歸「特殊空間與孔」。

## 內臟的前後層次（外層淡化）

題目是較深層的內臟（胰、十二指腸、升降結腸、脾、膽囊、腎、腎上腺、輸尿管）時，位於它前方的內臟（胃、橫結腸、空腸、迴腸、繫膜）變成淡色半透明、不能被點選，讓目標看得見。層次：前層（胃、橫結腸、乙狀結腸、空腸、迴腸、小腸繫膜與橫結腸繫膜、結腸帶）、中層（胰、十二指腸、升降結腸、盲腸與闌尾、迴盲交界、脾、膽囊與肝外膽管）、深層（腎、腎上腺、輸尿管）。規則 `coversTrunkTarget`；肌肉、血管與神經題目不用層次。

## 答題後資訊卡

內容只用主站已有的資料：肌肉、骨、神經與血管用各自類型的欄位（起點、止點、作用、神經支配…），器官、繫膜與韌帶顯示該構造的資料卡內容。欄位沒有資料時顯示「尚無資料」，不補寫。

## 名稱接受寫法

顯示名稱用主站的名稱。必考清單的用詞和主站不同時，清單的中文與英文名稱另外當作可接受的寫法（存在題庫每個構造的 `aliases`），例如「髂腹股溝神經」「迴結腸動脈」。左右是名稱一部分的構造只在完全相同時才接受，不會把左胃動脈的寫法套到右胃動脈。

## 檢查

`scripts/test-quiz-trunk.mjs`：每個區段與類別都有題目、每個構造有網格與唯一區段、中英文名都有、沒有重複、沒有一個名稱對兩個構造、沒有筆記字樣與廣東話、資料卡欄位有文字、深層內臟被前層遮住的規則、每個區段與系統都可成題。`scripts/report-quiz-trunk.mjs --check`：`docs/quiz-trunk-pool.md`（可出題構造、排除清單、必考清單覆蓋）與題庫一致。
