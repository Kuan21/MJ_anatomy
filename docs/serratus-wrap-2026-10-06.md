# Serratus circumference guide

The serratus candidate binding now interpolates around an elliptical thorax
circumference instead of applying a blended rotation about the shoulder girdle.
The ellipse is derived from the atlas rib bounds. Source radial detail is retained;
angular position, height and radius interpolate between the original point and
its scapular-carried counterpart. The existing fitted attachment weights still
determine progression. Rib anchors, scapular anchors, duplicate source seams and
exact neutral reset are preserved. No meshes or motion controls are hidden.

Both reported poses (32/162/48 and 161/36/0 degrees) are included in regression
tests, along with the previous sequence. The test checks source seams and the
radial envelope, not just finite geometry. Existing shoulder/body/nerve and sheet
constraint tests remain unchanged. An actual-geometry before/after export can be
generated by `node scripts/review-shoulder-pose.mjs` after the soft-tissue and
surface-constraint tests.

Limitations: a bounds-derived ellipse is not the actual rib/chest surface, and
this is not a contact solver, active muscle model, or validated volume-preserving
serratus simulation. The existing surface edge guard is still applied afterwards.
Visual changes are limited; this does not repair all broad shoulder muscles.

An affine neurovascular interpolation experiment reduced outward bulging but
flattened vessel calibre. It was rejected and is not included. Neurovascular
motion is unchanged in this commit; its floating routes remain unresolved.
CPU geometry inspection is not an iPad/WebGL performance or appearance test.
