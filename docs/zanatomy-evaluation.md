# Z-Anatomy 血管與神經評估報告（穩定期補充第 3 節）

使用者要求：先評估，**不要直接替換**。本報告比較 Z-Anatomy 與現有模型的血管、神經覆蓋率與連續性，列出授權條件、檔案大小與載入影響。沒有改網站、模型或任何檢查，也沒有把 Z-Anatomy 的資料放進 repo。

## 2. 發現：站上已有的 Z-Anatomy 資料，有四項不是取自官方倉庫
`public/model_sources.json` 與各 ATTRIBUTION 記載，下列資料取自第三方 GitHub 複本 `nqwrc/3d-anatomy`（標為「Z-Anatomy export」），不是官方倉庫：
| 站上檔案 | 內容 | 記載的來源 |
| --- | --- | --- |
| `nervous.glb`、`nerve-stream`、`stream/nerves-*` | 全身神經（現行神經系統） | nqwrc/3d-anatomy |
| `joints.glb` | 關節組織 | nqwrc/3d-anatomy |
| `neck-vessels.json` | 頸部血管 | nqwrc/3d-anatomy，commit `8ca3b74…` |
| 心臟詳細模式 `cardiovascular.glb` | 心臟、瓣膜、冠狀血管 | nqwrc/3d-anatomy，commit `8ca3b74…` |
另外腦詳細模式使用 `itayinbarr/brainproject`（記載為 Z-Anatomy 衍生）。

這與「只從官方來源取得、不可使用他人改作過的檔案」不一致，是在這次評估中發現的既有狀況。**建議另開一項工作：** 用官方檔重新生成上述資料（官方倉庫有 `NervousSystem100.fbx`、`CardioVascular41.fbx`、`Joints100.fbx`），並比對與現行資料的差異後再決定；在使用者決定前不動。

## 3. 比較方法與限制（請先看）
- 名稱比對：把兩邊名稱正規化（去側別字樣、底線與連字號、括號）後逐字比對。兩邊用字不同的（例如複數、拉丁文與英文、「…of left lung」）會被當成「不相符」，所以**「Z-Anatomy 才有」的數字是上限，不是缺口清單**。
- 區域：Z-Anatomy 的座標是公分、Y 向上、約 170 cm 高；以網格中心的位置粗分為上肢、下肢、軀幹與頭（以已知肱動脈、橈動脈、股動脈、膕動脈的位置校準），只是估計。
- **沒有做座標對齊**：沒有量位置準確度與口徑，只比名稱、連續性與檔案量。
- 站上的結構以大圖譜（BodyParts3D 4.0 與神經串流）加上示意血管名稱為準。

## 5. 連續性
以「兩個網格的表面點相距 2.5 mm 內視為相連」，計算相連的組數（越少越連續）：
| 類別 | Z-Anatomy | 站上大圖譜 |
| --- | --- | --- |
| 動脈 | 402 件分成 5 組，最大一組 398 件 | 641 件分成 16 組，最大一組 443 件 |
| 靜脈 | 231 件分成 7 組，最大一組 206 件 | 406 件分成 7 組，最大一組 358 件 |

**Z-Anatomy 的動脈樹明顯比大圖譜連續**（幾乎是一棵樹）；靜脈兩邊相近。這是 Z-Anatomy 最有價值的地方：站上目前用示意連接管補大圖譜動脈的缺口。
中心線抽取（`scripts/lib/leg-centreline.mjs`）：Z-Anatomy 動脈 402／402、靜脈 231／231 成功，神經 280／284（失敗的是腦神經核團，不是管）。

## 6. 檔案大小與載入影響
| 項目 | Z-Anatomy 原檔三角形 | 站上現行三角形（未簡化的原始量） |
| --- | ---: | ---: |
| 動脈 | 96.3 萬 | 33.7 萬 |
| 靜脈 | 50.6 萬 | 30.8 萬 |
| 神經（含神經核團等） | 121.0 萬 | 146.9 萬 |
站上現行大圖譜封包壓縮後約 33 MB，神經串流約 11 MB，示意血管約 9.6 MB。Z-Anatomy 的動脈約是現有的 2.9 倍，若直接採用且不簡化會明顯增加載入量；必須套用本站既有的簡化（每件誤差上限 0.2%）後才能估實際大小，這次沒有做。

## 7. 建議（請使用者決定）
1. **不替換。** 名稱數量上 Z-Anatomy 在四肢沒有明顯更完整，替換的風險（位置、口徑、載入量、重做資訊卡與測驗關聯）大於好處。
2. **（建議優先）把第 2 節的四項第三方複本資料改為官方來源**，先比對差異，再決定是否重新生成；這是授權與出處的一致性問題。
3. **（選用）用 Z-Anatomy 官方動脈補現有大圖譜動脈的缺口**：取代目前用示意連接管補的位置，並提供連續的樹狀結構。需要先做座標對齊（用兩邊共有的骨），再逐條核對位置，這部分的最終核對由使用者進行。
4. 若採用任何一項，網站加「模型來源與授權」頁。
