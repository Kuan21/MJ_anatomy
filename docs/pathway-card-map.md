# 資訊卡「播放走向」對照表（草稿，待確認；不部署）

規則：點開某結構的資訊卡時，若該結構在下表，卡片出現「播放走向」按鈕，按下進入全頁走向動畫並直接跳到該步驟（之後照常自動播放）。
- 步驟編號：N＝神經第 n 步、V＝血管第 n 步。
- 一個結構出現在多個步驟時，跳到它是主角的那一步；總覽步驟（N11、V11）不作為跳轉目標。
- 卡片名稱取自網站目前的結構名稱（血管來自模型分件、神經來自神經模型）。**沒有對應卡片的路徑（例如下肢「臀下神經」）不會有按鈕**；不在下表的結構不顯示按鈕。
- 動畫只畫**右側**肢體。

## 需要你決定的事
1. **左側結構要不要有按鈕？** 動畫只畫右側。建議：左側卡片不顯示按鈕。（另一種：左側卡片也顯示，但標示「示範為右側」。）
2. **Axillary vein 與 Median antebrachial vein**：動畫的「肘正中靜脈」不是模型裡的「前臂正中靜脈」，建議後者**不**加按鈕；腋靜脈放 V10（貴要靜脈到大圓肌下緣成為腋靜脈）。
3. **比動畫細的結構**（例如各指的固有掌指動脈、各肌肉支）：建議也跳到所屬那一步；要不要只留較大的結構，請決定。
4. **沒有對應的路徑**：原型有、網站沒有同名卡片的結構（例如下肢臀下神經、上肢外胸神經以外的一些細支）不會有按鈕。要不要另外補卡片，是另一個「新增解剖內容」的 PR。
5. **關閉動畫後**：回到原本的卡片、視角與選取狀態（與目前動畫關閉行為一致）。
