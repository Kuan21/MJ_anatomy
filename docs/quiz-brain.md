# Quiz「腦」的題庫規則（內部文件）

位置：Quiz → 器官 → 腦（`#/quiz/brain`）。第一級（點出位置）、第二級（學習關卡）、第三級（看結構寫名稱）與之後的模擬跑考共用同一個題庫，由 `public/models/quiz-brain.json` 產生。
實際題數、每一個不出題的構造與原因，見自動產生的 `docs/quiz-brain-pool.md`（`node scripts/report-quiz-brain.mjs`，請勿手改）。資料卡缺漏見 `docs/quiz-card-gaps.md`。

規則寫在 `app/quiz/brain.ts`，分組沿用主站腦部畫面的群組（`app/organ/brain-catalogue.ts` 的 `BRAIN_GROUPS`），不改動腦部畫面本身。

## 一、哪些構造可以出題

來源是主站腦部畫面使用的同一個腦模型（`public/models/brain.glb`），每個有標籤的節點是一個候選構造，頂點處理與主站相同（同一節點的多片網格合併並焊接、第四腦室用同一個重建、腦神經只畫靠近腦的一段）。唯一不同：主站再做的一次 Loop 細分沒有做（會讓整個腦由 12 MB 變成 46 MB），測驗改用焊接後的平滑法線上色。

要出題需要同時符合：

1. 有可畫的網格；
2. 有中文名（沿用主站腦部畫面的中文名，不新增）；
3. 名稱唯一：依第二級的辨識規則（`app/quiz/level2.ts` 的 `exclusionOf`、`nameCounts`，左右分開），再加一層更嚴的檢查——去掉左右後，英文名或中文名與另一個構造相同的（例如一個中線的上小腦腳與兩個左右的上小腦腳）一律不出題，因為打出名稱沒有唯一答案；
4. 不屬於下面的排除原因。

同一名稱同一側的多片網格合併成一個可點選的構造（與其他部位一致）。

## 二、不出題的構造與原因（逐項列在 `docs/quiz-brain-pool.md`）

| 原因 | 說明 |
| --- | --- |
| 示意構造 | 主站腦部畫面以橢球或管狀補上的形狀（內囊、帶狀核、視丘核團、下視丘核團）。模型本身沒有，測驗只用真實網格；若之後要考，需先決定示意形狀怎麼標示 |
| 腦膜 | 大腦鐮與左右小腦幕。會遮住其他題目，主站預設也關閉；要考需另做半透明處理 |
| 脊髓或脊椎的構造 | 脊髓前動脈、椎動脈。主站腦部畫面同樣不畫 |
| 顱外的腦神經分支 | 頰神經、頦神經、下齒槽神經、舌神經、下頷神經前後股、上頷神經腦膜支。主站預設關閉，只留腦神經根部 |
| 沒有可畫的網格 | 目前沒有 |
| 缺中文名 | 目前沒有 |
| 名稱重複 | 見產生的清單 |

任何新排除都必須在 `BRAIN_EXCLUSION_REASONS` 寫明原因，並由報告列出；測試（`scripts/test-quiz-brain.mjs`）核對「模型節點數 = 出題網格數 + 排除數」，不允許靜默漏掉。

## 三、分類對照

類別（沿用現有的十個類別，不新增）：

| 腦模型的群組 | 測驗的系統 | 類別 |
| --- | --- | --- |
| 腦神經（根部） | 神經 | 神經 |
| 腦動脈（含 Willis 環） | 動脈 | 動脈 |
| 靜脈竇與靜脈 | 靜脈 | 靜脈 |
| 其餘：皮質、基底核、間腦、腦室、白質纖維束、腦幹、小腦 | 腦構造（新系統，只在腦用） | 器官結構 |

「器官結構」在腦裡會佔多數；腦裡的細分由「區段」負責（見下），所以沒有另外新增類別。若之後想把灰質、白質、腦室分成獨立類別，需要使用者決定。

## 四、區段（部位選單）

由上到下依「腦葉 → 深部 → 腦幹與小腦 → 神經與血管」排列，每個區段是主站腦部畫面的一組群組：

| 區段 | 群組 |
| --- | --- |
| 額葉、頂葉、顳葉、枕葉 | 同名群組（腦迴與腦溝） |
| 邊緣葉、腦島與葉間溝 | 邊緣葉、腦島、葉間溝裂、其他皮質表面（海馬在邊緣葉） |
| 基底核與深部灰質 | 基底核與深部灰質 |
| 間腦（視丘與下視丘） | 間腦 |
| 腦室與脈絡叢 | 腦室與脈絡叢（含透明中隔） |
| 白質纖維束與連合 | 白質纖維束與連合 |
| 腦幹 | 腦幹 |
| 小腦 | 小腦 |
| 腦神經根 | 腦神經（根部） |
| 腦血管 | 腦動脈、靜脈竇與靜脈 |

每個構造只屬於一個區段，十三個區段加起來剛好是整個題庫（測試核對）。

## 五、資料卡

答題後的資料卡只使用 `public/models/brain/neuro-cards.json` 已有的資料（主站腦部資訊卡用的同一份，文字是我們自己寫的），沒有新增或改寫任何文字：

- 卡片標題與構造英文名相同（括號內不計）者，直接用它的欄位；
- 構造沒有同名卡片、但資料指向它的只有一張卡片時，用那一張，並在第一行寫「所屬資料卡」，標明卡片講的是較廣的概念（例如視丘的卡片對應視丘的各個核）；
- 有多張候選卡片但沒有同名者，不猜，視為沒有卡片；
- 沒有卡片：顯示「尚無資料」，並列在 `docs/quiz-card-gaps.md`。

## 六、看得見嗎（深部構造怎麼出題）

主站腦部畫面在選取深部構造時，把皮質變成玻璃。測驗用同一個想法，但規則在 `app/quiz/brain.ts` 的 `coversBrainTarget`：

- 每個構造有一個「層」：皮質、埋在外側溝的皮質（腦島、顳橫回、顳平面）、包覆的大塊（中腦、橋腦、延腦、端腦白質）、小腦表面、白質纖維束與連合、深部（基底核、間腦、腦室、腦幹核團、海馬）、其他（血管、腦神經根）；
- 題目是深部構造時：皮質、腦島、包覆的大塊、小腦表面與穿過它的纖維束變成淡淡的半透明（不透明度約 9%），而且不能被點選，所以點得到、看得到的是深部構造；
- 題目是白質纖維束時：皮質、腦島、包覆的大塊與小腦表面變成半透明，其他纖維束仍是實心（它們是選項）；
- 題目是腦島等埋在外側溝的皮質或包覆的大塊時：只有表面皮質變成半透明；
- 其他題目不變，目標仍是黃色，其他結構照原本規則變淡。

學習者看到的：深部題目一開始就是「透過玻璃腦看深部」，不需要先移開皮質；腦葉分界的內側面（扣帶、楔前葉、楔葉等）請改選單側，才看得到內側面（另一側半球不畫），並可用「內側面」視角。
視角按鈕：前面、後面、側面、內側面、上面、下面、置中。

## 七、已知限制（待使用者決定）

- 腦中線結構在模型裡分左右兩半（中腦、橋腦、延腦、視交叉等），題目是「左橋腦」「右橋腦」，與模型一致；
- 括號中的限定詞（例如「額下回蓋部」「（上部）」）在第三級會讓括號前的名稱也被接受；同一括號前名稱有多個部位時（例如扣帶回的四個部分），只寫括號前的名稱也算對。這是第三級現有的判分規則，沒有為腦修改；
- 第四腦室使用主站畫面的重建形狀（模型原本是胖鐘形），與主站一致；
- 示意構造與腦膜暫不出題（見上表）；
- 整個腦的網格約 26 MB（壓縮後 13 MB）。每題只載入單側與該題畫出的構造（腦構造題不畫血管與神經根；血管或神經題畫腦的淡色背景加同類構造），單側題最多不到 8 MB（測試核對），第一次比較久；
- 有 18 個構造的中文名帶有拉丁字母的編號或人名（大腦中動脈 M1／M2／M3 段、上縱束 I／II／III、眶溝（H 形眶溝）、中間初級溝（Jensen 溝）、動眼神經副核（Edinger-Westphal 核）），沿用主站腦部畫面的中文名，沒有自行翻譯；`scripts/test-region-quiz.mjs` 只對腦放寬這幾種寫法，其他英文字仍會失敗；
- 上小腦腳：模型有三個同名網格。左、右兩個維持「左小腦上腳」「右小腦上腳」並正常出題；中線的第三個網格依位置判斷是小腦上腳交叉，使用者已確認命名為「小腦上腳交叉（Decussation of superior cerebellar peduncles）」，只開放第三級（見「八」）；中文名「小腦上腳」是使用者指定的寫法，與「中小腦腳」「下小腦腳」的詞序不同，待使用者決定是否統一；
- 約三分之一的構造沒有同名的資料卡（資料卡多半是較廣的概念），顯示「尚無資料」，不自行配對；補法是在 `docs/neuro-card-text/` 補卡片，或指定構造與卡片的對應。

## 八、上小腦腳同名處理與「只開放部分級別」旗標

改名與旗標只有一個來源：`app/organ/brain-overrides.ts` 的 `BRAIN_OVERRIDES`。它由主站腦部畫面（`describeBrainNode`：名稱、搜尋、資訊卡）、網站搜尋索引（`scripts/prepare-search-index.mjs`）與測驗（`scripts/prepare-quiz.mjs`）共用，所以主站與測驗的名稱一致；沒有移動或重塑任何網格。

旗標（`quiz`）：`levels` 指開放哪幾級（1＝給名稱找結構、3＝看結構寫名稱）、`lessons` 是否收進學習關卡（第二級）、`exam` 是否收進將來的模擬跑考題庫，`reason` 寫在題庫報告。程式只讀目錄裡的 `availability` 欄位：第一級題庫（`questionPool`）、第三級題庫（`namingPool`）、學習關卡（`buildLessons`）、第一級畫面的背景（`sceneStructures`）與鄰近構造清單（`neighbours`）都依它過濾；模擬跑考做出來時用 `inMockExam`。`scripts/check-quiz-banks.mjs` 容許第一級與第三級題庫相差的，剛好就是旗標限制的構造，其他任何差異都會讓檢查失敗；學習關卡「每個構造恰好在一個關卡」的檢查，同樣把旗標排除學習關卡的構造視為合法地不在任何關卡。

目前只有一個構造有旗標：小腦上腳交叉（中線網格），`levels: [3]`、`lessons: false`、`exam: false`，原因「只開放第三級；不入學習關卡與模擬跑考（大體標本表面看不到）」。它的資訊卡有一行「說明 Note」（中英文，內容固定，寫在 `docs/neuro-card-text/x002.json`，主站卡片同一句在 `DECUSSATION_NOTE`，測試核對兩邊相同）。

左右判斷：兩個小腦網格的包圍盒中心 x 為 +0.0092 與 -0.0092；同一座標系下左橋腦中心 x 為 +0.0091、左下丘為 +0.0068，所以 +x 是左側，與模型標示相符。準備題庫時，位置與標示不符會直接中止（表中的 `x` 欄位）。

中線網格的位置依據（腦檔座標，單位公尺，+x 為身體左側）：
- 包圍盒 x -0.0157 至 +0.0189、y 1.5894 至 1.6107、z -0.0238 至 -0.0051；是封閉的管狀網格（956 個三角形、沒有開放邊），中段厚度約 3 mm，不是薄片，所以不是上髓帆（髓帆是跨在兩側小腦上腳之間的薄片）。
- 兩端接在左、右小腦上腳：與左小腦上腳最近距離 0.4 mm，與右小腦上腳 0.06 mm。
- 弧形走向：兩側端在較低較後（y 約 1.589，z 約 -0.022），越過中線時抬高並往前（y 1.6107、z -0.0051），最高點位於下丘的高度範圍（y 1.6013 至 1.6153），在下丘（z -0.0203 至 -0.0121）與中腦導水管（z -0.0154 至 -0.0092）的前方，落在中腦的包圍盒內。
- 第四腦室的 y 範圍是 1.5646 至 1.6013，紅核是 1.6036 至 1.6164；中線網格的 y 範圍（1.5894 至 1.6107）橫跨腦室上端到紅核下端之間的高度。
- 3D 畫面（背面與正中矢狀切面）的對照圖附在 PR 說明；它是獨立的 three.js 畫面，不是測驗的畫面。

M3 寫法：模型把大腦中動脈的節段寫成 M1-segment（兩側）、M2-segment（左）、M2（右）、M3 segment（左）、M3-segment（右），連字號寫法最多，所以左右各一對都統一成連字號寫法（M2-segment、M3-segment），中文統一為「（M2 段）」「（M3 段）」。
