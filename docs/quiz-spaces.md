# Quiz 類別「特殊空間與孔」（上肢、下肢）：規則

四肢的特殊空間（四邊孔、三邊孔、三邊裂、三角肌胸大肌三角、腋窩、肘窩、解剖鼻煙盒、腕隧道、股三角、內收肌管、內收肌裂孔、膕窩、跗管）是獨立的題目類別 `space`，可在第一級（找結構）、第二級（學習關卡，由同一題庫產生）與第三級（寫名稱）作答。實際題數與每一項排除清單由 `node scripts/test-quiz-spaces.mjs --write` 產生在 `docs/quiz-spaces-pool.md`。此檔為內部說明，不出現在網站上。

## 網站上有哪些特殊空間、怎麼呈現

特殊空間的資料在 `app/mj-spaces.ts` 的 `SPACES`（分層解剖 → 特殊區域清單）：每一個空間列出邊界構造、頂、底與通過的內容物，每一項是主圖譜中真實存在的構造（用名稱樣式對應到網格，神經用神經模型的基本名稱）。空間本身沒有實體網格；主圖譜在該空間的中心點（`app/space-ranges.json`，由 `scripts/compute-space-ranges.mjs` 算出各邊界與內容物網格最靠近的交會處）半徑內把邊界與內容物高亮，其餘淡化。測驗沿用同一份資料，不另外建立任何形狀。

| 特殊空間 | 部位 | 邊界／頂／底／內容物的來源 | 結果 |
| --- | --- | --- | --- |
| 四邊孔、三邊孔、三邊裂、三角肌胸大肌三角、腋窩 | 上肢 | `SPACES`，肌肉、骨、血管、神經皆為圖譜構造 | 出題（缺的構造不畫，見下） |
| 肘窩、解剖鼻煙盒、腕隧道 | 上肢 | 同上；解剖鼻煙盒的三條肌腱、腕隧道的屈肌腱用圖譜的肌腱構造 | 出題 |
| 股三角、內收肌管、內收肌裂孔、膕窩、跗管 | 下肢 | 同上 | 出題 |
| 坐骨小孔 | 下肢（髖） | 邊界為坐骨棘與坐骨結節（圖譜沒有獨立網格），內容物多數不在題庫 | 不出題（見排除原因） |
| 枕下三角 | 背部 | `SPACES` | 背部尚未開放特殊空間，不出題 |
| 主動脈裂孔 | 胸腔 | `SPACES` | 胸腔尚未開放特殊空間，不出題 |
| 坐骨大孔、閉孔管、股管（股環） | | 網站的特殊區域清單沒有這些項目 | 不存在，不編造 |

## 題目怎麼呈現（學習者看到什麼）

空間沒有自己的網格，題目畫的是「圍成空間的真實構造」與「通過的真實構造」，不畫平面、圓盤、圓柱或任何新形狀：

- 第一級（給名稱找結構）：畫面是該空間周圍 6 公分內的骨、肌肉、肌腱、神經、動脈、靜脈，全部同樣不透明、沒有淡化（淡化會洩漏答案）。學習者點選任何一個圍成該空間的邊界、頂、底構造或通過的內容物即答對；點到其他構造答錯，被點到的構造標紅色。作答後，圍成空間與通過的構造以綠色高亮（整條構造都畫，不切割、不另加形狀），顏色在空間中心最濃、往各構造的遠端漸淡；其餘構造淡化。「放大正確位置」把鏡頭對準空間中心，並沿用特殊區域清單的觀看方向（`SpaceDef.look`）。「移開遮擋」可先移開表面構造。
- 第二級（學習關卡）與第三級（寫名稱）：空間的邊界、頂、底與內容物全部以黃色標示（目標色，同樣在空間中心最濃），其餘構造淡化（可用滑桿調整清晰度，或勾選「只看目標」）；鏡頭由系統挑一個「空間附近的目標部分看得到」的角度（只用空間範圍內的頂點判斷，不看整條肌肉）；作答後顯示答案卡。
- 答案卡：只用既有資料。「位置」取自該空間資訊卡已有的位置說明；「邊界」「內容物」取自特殊區域清單（含各構造的位置，例如「上界」「外側界」）。題庫沒有該構造而沒畫出的項目，會標示「（本題未畫出）」；沒有資料的欄位顯示「尚無資料」，並列在 `docs/quiz-card-gaps.md`。

## 可出題的條件

一個特殊空間必須同時符合（規則在 `app/quiz/spaces.ts`，建置與測試讀同一份）：

1. 在上肢或下肢（`SPACE_REGION`）。
2. 有各側的中心點資料（`app/space-ranges.json`），而且各邊界與內容物網格的交會距離不超過 5 公分（交會不明確時畫面無法指出空間位置）。
3. 題庫裡畫得出至少兩個邊界、頂、底構造，而且清單所列邊界、頂、底項目至少有一半題庫有；至少畫得出一項通過的內容物。
4. 名稱在同部位內唯一，並有中文名（沿用特殊區域清單的中文名，不新增、不改名）。

排除的空間一律列在 `docs/quiz-spaces-pool.md`，附原因，不會無聲略過。

## 排除原因一覽（與 `app/quiz/spaces.ts` 的 `SPACE_EXCLUSION_REASONS` 完全相同，由測試核對）

- 不在上肢或下肢（背部、胸腔的特殊空間尚未開放測驗）
- 沒有各側的中心點資料（app/space-ranges.json），無法把鏡頭對準這個空間
- 各邊界構造的交會處不明確（交會距離超過 5 公分），畫面無法指出空間位置
- 題庫裡畫得出來的邊界、頂與底構造不到兩個，或所列邊界、頂與底項目有一半以上題庫沒有
- 題庫裡沒有任何一項通過的內容物可以畫出
- 名稱與同部位其他構造重複

## 範圍與分段

- 每個空間在「全部部位」中出題，並屬於一個分段（以空間中心高度所在的最窄分段決定，與關節構造相同）。
- 題庫範圍（只考摘要範圍）依既有的 `scopeOf` 判定。
- 左右：每個空間有左、右兩個構造（名稱 Left／Right，中文 左／右）。
