# Quiz「耳」的題庫規則（內部文件）

位置：Quiz → 器官 → 耳（`#/quiz/ear`）。第一級（點出位置）、第二級（學習關卡）、第三級（看結構寫名稱）與之後的模擬跑考共用同一個題庫，由 `scripts/prepare-quiz.mjs` 從耳詳細模式的模型檔產生 `public/models/quiz-ear.json`。名稱、分組與資訊卡來自 `app/mj-ear-atlas.ts`，不另外維護一份。

## 題庫

- 22 題：耳廓、鼓膜、錘骨、砧骨、鐙骨、前庭、前／外側／後半規管、前庭階、鼓階、橢圓囊、球狀囊、三條半規導管、三個壺腹、顏面神經（顳骨內段）、鼓索神經、耳蝸神經。
- 分區（`app/quiz/catalogue.ts` 的 `EAR_SECTIONS`）：外耳、中耳、骨性迷路、膜性迷路、耳內神經；每題只屬於一個分區。
- 類別：聽小骨為骨，神經為神經，其餘為器官結構（系統 `ear`，只在耳 Quiz 出現）。
- 單一右耳，所有構造的左右為「midline」，設定頁的左右選擇不影響題庫；視角預設從外側看。
- 網格直接取自 `ear-atlas.bin.gz`，不另外加工（`scripts/test-region-quiz.mjs` 逐位元組比對）。

## 不出題的構造（每項的原因寫在 `.sites-runtime/quiz-ear-report.json`）

| 原因 | 構造 |
| --- | --- |
| 示意管道：位置與大小為估算 | 外耳道、咽鼓管 |
| 標在骨面上的色塊，不是獨立構造 | 卵圓窗、圓窗 |
| 沒有網格，只有資訊卡 | 鼓室腔、鼓膜張肌、鐙骨肌、耳蝸管、內淋巴囊、前庭神經、前庭耳蝸神經、螺旋神經節、前庭神經節、膝狀神經節 |

## 畫面

題目是內層構造時，位於它外側的層會變成淡淡的玻璃，也不能點選（`app/quiz/ear.ts` 的 `coversEarTarget`）：耳廓 → 鼓膜 → 聽小骨與神經 → 骨性迷路 → 膜性迷路，由外而內；同一層的構造不互相遮蔽。鏡頭最近距離為 1 公分（`frame.minDistance`），其他區域維持原來的 28 公分。

## 資料卡

答題後的資料卡有四欄（位置與形態、功能、血液與神經供應、補充；沒有該欄的構造不顯示），中英文並列，與詳細模式相同。
