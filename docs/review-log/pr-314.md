【需人工審核】，未合併。使用者 2026-11-14 指示。疊在 #311 上面，請先審 #311。

眼詳細模式新增可收合的「眼眶的管與裂」：三個開口直接標示在骨面上（沒有新增模型），選一個開口時通過的構造變色、其他構造淡化，附中英說明與模型沒有的通過構造；「對準」按鈕把鏡頭轉向眼眶尖（只在按下時移動）。位置在建置時決定：視神經管取視神經被蝶骨包住處，眶上裂取六條神經穿過蝶骨處，眶下裂取蝶骨與上頜骨在眶底後方的縫。PR 附 GIF 與桌面、手機的前後截圖。

**2026-11-15 使用者指示後的修改：** 通過構造依使用者清單核對（上眶裂加上總腱環內外的區分；下眶裂加上下眼靜脈分支）；名稱改為上眶裂、下眶裂（另一寫法眶上裂、眶下裂在畫面上以「又稱」顯示）；「對準」的鏡頭拉遠並加上方位提示；必備結構清單的已知缺口因此少兩項（上眶裂、下眶裂）。

**等我審核：** 三個標示的位置，尤其是眶下裂（沒有通過構造可以對照，純粹由骨的幾何推出）；三段中英說明（`app/mj-eye-openings.ts`）。

**未完成：** 其他孔另開 PR，次序：眶上孔（眶上切跡）、眶下孔，然後前篩孔、後篩孔。
