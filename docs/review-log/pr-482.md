- 深層內臟為題時前方內臟變淡玻璃的次序（前層：胃、橫結腸、空腸、迴腸、繫膜；中層：胰、十二指腸、升降結腸、脾、膽囊；深層：腎、腎上腺、輸尿管）。

- 答題後資訊卡只顯示主站已有的資料，沒有資料的欄位顯示「尚無資料」。
