眼詳細模式新增「眼球動作」：六條眼外肌各一個按鈕，眼球由正視位置轉到該肌肉的動作方向並選取該肌肉；動眼、滑車、外旋神經麻痺各一個按鈕，顯示靜止眼位，失去作用的肌肉變灰，動眼神經麻痺瞳孔放大。眼球轉動時六條肌肉的止點與視神經前端跟著走。PR 附 GIF 與桌面、手機的前後截圖。

**等我審核：** 每條肌肉的動作方向與神經支配；三種麻痺的眼位；九段中英說明文字（`app/mj-eye-movement.ts`，新寫的一般解剖描述）。角度是示意值。

**未完成：** 上眼瞼下垂沒有呈現（只寫在說明）；外旋神經模型沒有；輻輳、九個注視方向、雙眼協同動作沒有做；「眼球動作」讓桌面面板的圖層清單變短，是否改成可收合待決定。
