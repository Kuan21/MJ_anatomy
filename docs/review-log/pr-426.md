改了什麼：新增胃詳細模式（共用模板）：胃的分區與大小彎等表面標示；動脈、靜脈（含門靜脈屬支）、神經分開看與「全部」總覽；相關肌肉（橫膈左半，半透明）在「器官」與「全部」一起顯示；切面、逐層剝離、搜尋、資訊卡（55 個構造）、Quiz 胃篇。

等使用者核對：做法（GIF 與五個分組截圖）是否可以套用到其他器官；胃的分區邊界、示意血管神經的位置；已知限制（部分血管貼入胃壁、後迷走神經幹沒有單獨一項、腸繫膜下靜脈沒有放）是否要處理。

未完成事項：使用者看過做法後，才做十二指腸、胰、脾 → 肝膽 → 腸 → 腎。
