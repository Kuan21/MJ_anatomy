改了什麼：依 #426 審核意見修正胃詳細模式：
- 胃大彎、胃小彎改為貼著胃表面的平滑窄帶（深炭灰、深綠）。
- 神經與血管逐段檢查兩端：懸空碎段刪除，3 mm 內的神經缺口補連接管。
- 腹腔叢沿動脈走，並加入腹主動脈一小段。
- 後胃動脈與後胃靜脈接上胃後壁後沿後壁上行，並分出小支。
- 中英文名稱改用必考清單寫法；Quiz 接受舊名稱作為第二種寫法。

等使用者核對：
- 大小彎窄帶的顏色與寬度。
- 神經與靜脈視圖是否還有沒接上的段。
- 示意血管與神經的位置。

未完成事項：
- 胃管、食道胃交界（Z 線）沒有內面模型，只有資訊卡。
- 左胃動脈食道支、食道靜脈由 A4–A5 在主圖譜做。
