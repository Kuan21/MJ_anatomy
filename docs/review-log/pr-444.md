改了什麼：腦部詳細模式新增「Willis 環血流｜Circle of Willis」動畫，四步：入環（內頸動脈、椎動脈、基底動脈）、Willis 環組成、前中後大腦動脈與供血區、阻塞與側支循環。可選 11 條動脈之一阻塞（含「後交通支細小」變異），方向倒轉的段標橘色，供血區顯示血流下降或缺血。動脈全部是腦部模型原有的，沒有改任何模型、資訊卡或 Quiz。

等使用者核對：
- 各阻塞結果是否符合教學重點（內頸動脈阻塞：環完整時血流下降、後交通支細小時缺血；中大腦動脈、A2、P2 阻塞：缺血）。
- 供血區以整個腦迴劃分是否可接受。
- 動脈路徑與交會點位置；iPad 直向與橫向操作。

未完成事項：
