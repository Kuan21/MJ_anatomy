改了什麼：左右腎門處把腎靜脈向前、腎動脈向後、腎盂（輸尿管上端）稍向後移（載入時位移，不改來源模型），腎門由前到後成為腎靜脈、腎動脈、腎盂。腎內分支與輸尿管不穿出腎臟、與腎上腺保持 1.5 mm。

等使用者核對：兩側腎門次序（PR 截圖，「上面」視角圖上方是身體前方）；決定腎竇內局部變形（只在隱藏腎臟時看得到）是接受還是繼續改。

使用者決定（2026-11-17）：選 1，接受隱藏腎臟時腎竇內局部變形為已知限制（腎臟顯示時看不到），列入待辦，12/10 前修。
