【需人工審核】。

**改了什麼：** 肩外展 158° 時畫面左側懸空的紅色血管段，是右／左胸肩峰動脈胸肌支的末端接頭。接頭（`<id>-END`）與血管本體分屬不同資料包，載入先後不固定；動作解算只在同一批輸入裡找本體，接頭若在另一批到達，就只用自己靠胸壁的權重，本體跟著胸大肌移動時它留在原地。`createShoulderSolver` 改為跨批次記住血管本體與等待本體的接頭，哪一方後到都重新接上。沒有改模型、權重或關節動作。

**與 #270 的關係：** 不是同一原因。#270 修的是接頭權重讀取位置；這次是載入順序。

**回歸測試：** `scripts/test-vessel-end-arrival.mjs`（登記在 `scripts/checks/motion.d/`）：141 個末端接頭在三種到達順序（同一批、本體先、接頭先）下的綁定權重與解算位置完全一致；同一測試在修正前失敗。

**等使用者核對：** PR 內的前後對照截圖；只在軟體繪圖下看過，請在自己的電腦與 iPhone 上，於頁面仍在載入時擺肩外展姿勢確認。
