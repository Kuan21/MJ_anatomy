改了什麼：
- 胃大彎、胃小彎、胃角切跡、賁門切跡改為部位名詞：平時不顯示；選取或 Quiz 問到時，用統一的選取高亮色沿胃邊緣顯示約 1.5 mm 細線（共用檢視器 `term` 標示）。
- 資訊卡改寫為胃的邊緣或角，以及附著的結構。
- 器官詳細模式入場預設「全部」視圖（共用頁面）。
- 後胃動脈與後胃靜脈在胃後壁上順向延伸。

等使用者核對：
- 細線寬度與高亮色。
- 入場的「全部」視圖。
- 四項部位名詞的資訊卡文字。

未完成事項：
- 胃小彎細線右側視角中段有小鋸齒；更平滑需要再細分網格。
