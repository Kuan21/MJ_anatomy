# 會陰缺少的模型清單（內部文件，不上網站）

2026-11-16。只列結構名稱與來源狀況，供使用者挑選要先做哪幾項；這個 PR 不新增任何模型。

## 來源核對結果

- Z-Anatomy（CC BY-SA 4.0，本專案已使用的版本）：逐一檢查了肌肉模型與內臟模型兩個檔案的網格名稱。會陰只有一個「會陰肌群」組合節點與外肛門括約肌（圖譜已有）；沒有球海綿體肌、坐骨海綿體肌、會陰淺／深橫肌、尿道括約肌、會陰體、大小陰唇、陰蒂、前庭、陰道口、尿道口。內臟檔的陰莖、尿道圖譜已有。
- BodyParts3D（圖譜主要來源）：圖譜裡的會陰肌肉只有「會陰淺層肌群」與外肛門括約肌；沒有其他會陰肌肉與外陰部件。未逐一核對 BodyParts3D 全集，只依圖譜現有部件判斷。
- 其他開放來源：未找到可用的、授權清楚的外陰與會陰肌肉網格。

結論：下表需要新增的項目，目前都只能依公開圖譜（Gray's Anatomy 1918、OpenStax）自行建模，沒有現成網格可取。

陰蒂與前庭球已由 #333 合併，不在清單內。自建前先查 BodyParts3D 完整部件清單（FMA 名稱），有就用，沒有才自建。肌肉另開 PR。

2. 會陰體
3. 會陰深橫肌、尿道外括約肌（有額度先做）
4. 大小陰唇：考試後與女性鼠蹊部重建一起做；有機形狀依兩輪規則，不像就停下回報

## 其餘缺少的項目

| 結構 | 建議 |
| --- | --- |
| 外肛門括約肌 | 圖譜已有，只核對位置與左右 |
| 陰道口、尿道口 | 前庭內的區域標示，不另做網格 |
| 會陰膜 | 薄的三角形纖維膜，要有厚度 |
| 會陰淺／深陷凹 | 區域標示：高亮邊界結構與內容物，不做平面或方塊 |
| 尿道陰道括約肌、尿道壓迫肌 | 只做資訊卡，或與尿道外括約肌一起做 |
| 旁尿道腺 | 有機小腺體，建議延後 |
| 陰莖球、陰莖腳 | 需要時從現有海綿體分出 |
| 陰莖懸韌帶、陰莖襻韌帶 | 帶狀韌帶，可自建 |
| 坐骨肛門窩、陰部管、肛門三角、泌尿生殖三角 | 區域標示 |
