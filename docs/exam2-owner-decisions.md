# 第二次考試範圍：頭頸與腹部「需使用者決定」事項表（內部文件，不上網站）

共 64 項：頭頸 18、腹部 46。來源：`docs/exam2-headneck-gap.md`、`docs/exam2-abdomen-gap.md` 標為「需使用者決定」者。

排序依據（價值由高到低；我無法確認實際考題範圍，不確定處在「建議」欄寫明）：
1. 先看缺口清單的優先級（高、中、低），並看是否為核心結構（主幹或大臟器排前面，小分支、潛在間隙、筋膜薄層排後面）。
2. 站上已有相近結構者（例如已有肌肉、血管可疊加）排前面，因為成本低、效果明確。
3. 同優先級內，易引起混淆的命名與呈現問題先決定，會影響後面一整組的先排。

本檔只是決定清單：「建議」是我的意見，不是定案；沒有任何項目宣稱經過解剖核對；沒有動任何模型。選項字母可直接回覆，例如「1A、2A、5–14A」。
