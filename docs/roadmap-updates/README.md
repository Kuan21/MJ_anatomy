# ROADMAP 更新檔

一般 PR 不直接改 `ROADMAP.md`。每個 PR 把總進度清單的變化寫成 `pr-<編號>.md` 放在這裡，合併後由 `node scripts/pr-docs.mjs sync` 併入 `ROADMAP.md`，併入後檔案移到 `applied/`。規則見 `CLAUDE.md`「每個 PR 的文件」。

格式（寫這個 PR 合併之後應該呈現的狀態）：

```
---
pr: 292
date: 2026-11-14
---

| 項目 | 狀態 | 相關 PR | 最後更新 | 下一步 |
| --- | --- | --- | --- | --- |
| 項目名稱 | ✅ | #292 | 2026-11-14 | 下一步或備註 |
```

- 「項目」與總進度清單現有的名稱完全相同：取代該列。名稱不同：在總進度清單最後一個表格新增一列。
- 狀態只用 ✅、🟡、⬜、❌、❓。
- 本資料夾不發布到網站，內容規則與 `ROADMAP.md` 相同。
