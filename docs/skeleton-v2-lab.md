# Skeleton v2 骨骼測試頁（開發者專用）

**入口**：僅在網址加上 `?dev=1` 才會開啟（例如 `https://…/?dev=1`）。主頁已不再顯示連結；沒有 `dev=1` 時，`?lab=skeleton-v2` 會回到一般圖譜。

## 目的
這是一個實驗頁，用來單獨檢查「上肢骨骼的連動層級」是否正確：

胸廓（根）→ 鎖骨 → 肩胛骨 → 肱骨 → 尺骨 → 橈骨 → 腕骨 → 手

每一側有 32 塊上肢骨。頁面讓開發者選取任一節點，以 X／Y／Z 軸做 ±15° 的小角度測試，確認子骨骼是否正確跟隨父骨骼，並可隱藏、單獨顯示骨骼，或在全身骨骼與上肢之間切換。

## 進度
- **第一階段（骨骼層級）已完成**：32 塊骨骼逐一綁定；父子連動、重複操作後可完全還原；缺漏或不符的綁定會直接拒絕，不會猜測。對應測試為 `scripts/test-skeleton-v2.mjs`（已包含在 `npm run check:motion`）。
- **此頁不是最終功能**：測試用的旋轉中心由模型邊界估算，並非已校準的生理關節動作；此頁只測骨骼，不含肌肉、神經與血管。
- **成果已被主圖譜採用**：主圖譜的上肢動作（肩肱節律、肌肉與皮膚變形等）使用同一套 `app/biomechanics-v2` 模組。此測試頁本身之後沒有再擴充，因此只作為開發者除錯工具保留。
- 原始設計與稽核紀錄見 `docs/BIOMECHANICS_V2_AUDIT.md`。
