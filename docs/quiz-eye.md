# Quiz「眼」的題庫規則（內部文件）

位置：Quiz → 器官 → 眼（`#/quiz/eye`）。第一級（點出位置）、第二級（學習關卡）、第三級（看結構寫名稱）與模擬考試共用同一個題庫，由 `scripts/prepare-quiz.mjs` 從眼詳細模式的模型檔產生 `public/models/quiz-eye.json`。名稱、分組與資訊卡文字來自 `app/mj-eye-atlas.ts` 與 `app/mj-eye-openings.ts`，不另外維護一份；那兩個檔案改了名稱或文字，下次 `npm run regen` 題庫就跟著變。本批只加 Quiz 資料與設定，沒有改模型，也沒有改眼詳細模式的資訊卡文字。

## 題庫

- 79 題 = 眼詳細模型的 72 項構造 + 眼眶的 7 個孔、管與裂（視神經管、眶上裂、眶下裂、眶上孔、眶下孔、前篩孔、後篩孔）。眼詳細模型的每一項構造都有網格，全部出題，沒有排除。
- 眼眶的孔、管與裂在模型裡不是獨立網格：眼詳細模式用顏色標在骨面上。Quiz 取同一批骨面頂點，把「至少有兩個被標記頂點」的三角形抽出來成為一片貼骨的小面（沿法線抬高 0.15 毫米，避免跟骨面閃爍），骨本身不動。
- 分區（`app/quiz/catalogue.ts` 的 `EYE_SECTIONS`，每題只屬於一個分區）：眼眶骨、眼瞼與淚器、眼外肌（含滑車、總腱環、制止韌帶）、眼眶神經與眼動脈、視神經與視覺路徑、眼球壁（纖維層、虹膜與睫狀體、脈絡膜、房水排出路徑）、視網膜（含鋸齒緣、視盤、黃斑部、中央小凹）、水晶體與眼內液。
- 系統與類別：眼眶骨為骨；六條眼外肌與提上眼瞼肌為肌肉；眼眶神經與睫狀神經節、視神經為神經；眼動脈為動脈；視交叉、視徑、外側膝狀體、上丘臂、上丘屬腦構造；其餘為眼構造（器官）。制止韌帶、水晶體懸韌帶、總腱環歸韌帶，眼眶的孔、管與裂歸「特殊空間與孔」。
- 單一左側眼眶，所有構造的左右為「midline」，設定頁的左右選擇不影響題庫；視角預設從外側（左側）看。
- 網格直接取自 `eye-atlas.bin.gz`，不另外加工（`scripts/test-region-quiz.mjs` 逐位元組比對；眼眶孔道的貼面除外）。

## 畫面

題目是較深層的構造時，位於它外側的層會變成淡淡的玻璃，也不能點選（`app/quiz/eye.ts` 的 `coversEyeTarget`）：眼眶骨 → 眼眶的孔道（貼在骨面上）→ 眼瞼與淚器 → 眼眶內容物（眼外肌、神經、眼動脈、視神經）→ 纖維層 → 葡萄膜（虹膜、睫狀體、脈絡膜）→ 視網膜與水晶體 → 視網膜標誌；同一層不互相遮蔽。房水與玻璃體本身透明，除了它們自己是題目以外一律淡化。鏡頭最近距離 1.2 公分（`frame.minDistance`）。

## 資料卡

答題後的資料卡是眼詳細模式同一段說明（中英並列）；眼眶的孔、管與裂多一欄「通過的構造」，列出模型裡有的內容物。

## 名稱

英文名與中文名取自眼詳細模式。必考結構清單（`docs/required-structures/head-neck.json`）寫法不同的中文名與英文名，第三級與學習關卡都接受（`app/quiz/eye.ts` 的 `EYE_NAME_ROWS`，以及頭頸統一名稱表 `app/mj-head-neck-names.json`）；`scripts/test-quiz-eye.mjs` 逐項檢查。

## 檢查

`node scripts/test-quiz-eye.mjs`（已列入 `npm run check`）。
