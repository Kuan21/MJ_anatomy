# Quiz「頭頸」的題庫規則（內部文件）

位置：Quiz → 頭頸（`#/quiz/head-neck`）。第一級（點出位置）、第二級（學習關卡）、第三級（看結構寫名稱）共用同一個題庫，由 `public/models/quiz-head-neck.json` 產生。
實際題數、每一個不出題的構造與原因，見自動產生的 `docs/quiz-head-neck-pool.md`（`node scripts/report-quiz-headneck.mjs`，請勿手改）。資料卡缺漏見 `docs/quiz-card-gaps.md`。

規則寫在 `app/quiz/headneck.ts`；準備題庫的程式在 `scripts/prepare-quiz.mjs` 的 `head-neck` 區塊。**沒有新增、修改任何 3D 模型**：題庫只用主站已經有、而且能點選的頭頸構造。腦（皮質、核團、腦室、白質、腦幹、小腦、腦血管、腦神經根）有獨立的「腦」Quiz，這裡不重複。

## 一、哪些構造可以出題

來源（都是主站已有的資料，網格沒有改動）：

| 來源 | 內容 |
| --- | --- |
| 主圖譜（BodyParts3D 的頭頸部位） | 顱骨與下頷、頸椎與椎間盤、舌骨、牙與牙齦、頸部與舌肌、咽喉肌、眼外肌、眼球與淚器、喉與鼻的軟骨、舌與唾液腺、眼眶的神經、椎動脈、眼動脈、頸深與頸淺動脈、下甲狀腺動脈 |
| 面部肌肉套件（facial） | 表情肌與咀嚼肌 |
| 補充套件（supplement） | 顳頂肌、降鼻中隔肌、頸長肌右側各部、頸棘肌、帽狀腱膜 |
| 神經疊圖（nerve-stream） | 十二對腦神經的完整走向與三叉神經分支（頦神經、頰神經、舌神經、下齒槽神經等）；枕大、枕小、第三枕、枕下與耳大神經為示意管狀模型（背部 Quiz 已使用，資訊卡標示示意模型） |
| 頸部血管套件（neck-vessels） | 總頸動脈、內頸動脈、外頸動脈、內頸靜脈（主站用它取代圖譜的同名網格，測驗同樣只用這一份） |
| 關節組織（joints.glb） | 顳顎關節囊、關節盤與韌帶、蝶下頷韌帶、莖突下頷韌帶、環咽韌帶 |
| 特殊空間（app/mj-spaces.ts） | 枕下三角（由邊界與通過的構造組成，沒有自己的網格） |

要出題需要同時符合：有可畫的網格；有中文名；名稱唯一（去掉左右後，英文名或中文名與另一個構造相同的，打出名稱沒有唯一答案，一律不出題）；左右成對的構造兩側都有名稱（Left／Right、左／右）；不屬於下面的排除原因。

## 二、不出題的構造與原因（逐項列在 `docs/quiz-head-neck-pool.md`）

| 原因 | 說明 |
| --- | --- |
| 腦的構造 | 圖譜裡的腦回、核團、腦室、白質纖維束、腦幹、小腦、腦膜、腦動脈與腦下垂體、松果體；已有獨立的腦 Quiz |
| 頸部血管套件取代 | 圖譜的總頸動脈、內頸動脈、內頸靜脈網格，主站畫面已改用頸部血管套件 |
| 重複來源 | 神經疊圖有完整走向時，圖譜較短的同一條神經（視神經、眼神經、滑車神經）不重複出題 |
| 屬於其他部位 | 胸椎、脊髓前動脈、斜方肌、沿全身走行的交感神經與神經節、臂神經叢 |
| 左右合成一個網格 | 外耳、眉毛：模型把兩側合成一個網格，無法分左右 |
| 不是解剖構造 | 頭髮 |
| 太細 | 睫狀神經節與鼻睫神經之間的交通支（中文名與主幹相同） |
| 只有單側 | 提上眼瞼肌腱與二腹肌中間腱，模型只有一側，單獨看不出是哪一條 |
| 缺中文名、名稱重複 | 目前以報告為準 |

任何新排除都必須在 `HN_EXCLUSION_REASONS` 寫明原因，並由報告列出；`scripts/test-quiz-headneck.mjs` 核對報告與題庫一致，不允許靜默漏掉。

## 三、類別與區段

類別沿用現有的十個類別，沒有新增：

| 內容 | 類別 |
| --- | --- |
| 顱骨、頸椎、椎間盤、舌骨、下鼻甲、淚骨 | 骨 |
| 表情肌、咀嚼肌、頸部肌肉、眼外肌、咽喉與舌肌 | 肌肉 |
| 腦神經、三叉神經分支、頸神經 | 神經 |
| 頸動脈、椎動脈、眼動脈等 | 動脈 |
| 內頸靜脈 | 靜脈 |
| 莖突舌骨韌帶、甲狀舌骨膜、聲帶韌帶、咽縫、帽狀腱膜、眼的制止韌帶與水晶體懸韌帶 | 韌帶與筋膜 |
| 顳顎關節與環咽韌帶 | 關節 |
| 枕下三角 | 特殊空間與孔 |
| 眼球與淚器、瞼板、舌、牙與牙齦、唾液腺、喉軟骨、鼻軟骨、會厭、氣管、唇 | 器官結構（新系統「頭頸器官構造」只在頭頸用） |

八個區段，每個構造只屬於一個區段（測試核對）：顱骨與下頷、頸椎與舌骨、面部與咀嚼肌、頸部肌肉、眼與眼眶、口鼻咽與喉、腦神經與頸神經、頭頸血管。

## 四、眼球內部怎麼出題

眼球的各層疊在一起（鞏膜與角膜在最外、脈絡膜與視網膜、玻璃體與前房、水晶體、虹膜、睫狀冠與懸韌帶在最內）。題目是眼球內部的構造時，同一側外面的幾層改為淡色半透明（不透明度約 9%）而且不能被點選，其他題目不變。規則在 `app/quiz/headneck.ts` 的 `coversHeadNeckTarget`，與腦 Quiz 的玻璃規則是同一個機制（`app/quiz/viewer.ts` 的 `isCover`）。其他深層構造（深層頸肌、咽肌、舌肌）沿用既有的「移開遮擋」。

## 五、資料卡

答題後的資料卡只使用主站已有的資料（肌肉、神經、動脈、靜脈、骨骼的資料卡欄位來自主站結構資料；腦神經根的神經卡片屬於腦 Quiz，這裡不引用）。「頭頸器官構造」目前沒有任何卡片文字，卡片顯示「尚無資料」，不自行補寫；其他系統沒有資料的欄位同樣顯示「尚無資料」並列在 `docs/quiz-card-gaps.md`。

## 六、已知限制與待使用者決定

- 模型沒有的構造不出題：顏面動脈、上頷動脈、淺顳動脈、外頸靜脈、腮腺、甲狀腺、副甲狀腺、扁桃體等（見 `docs/exam2-headneck-gap.md`，該清單只在內部）。
- 中耳、內耳與鼻腔內部沒有可點選的構造，不在範圍內。
- 神經疊圖的腦神經是整條走向，與腦 Quiz 的「腦神經根」（只到靠近腦的一小段）名稱相近但不同區域各自出題。
- 這個區域的 3D 畫面（鏡頭框、眼球半透明、深層構造的可見度）只在網頁截圖上看過，沒有在實機 GPU 與手機上確認。
