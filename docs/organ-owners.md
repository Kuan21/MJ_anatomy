# 血管與神經的歸屬器官（器官開關）

由 `node scripts/list-organ-owners.mjs` 產生，規則表在 `app/mj-organ-owners.ts`（`npm run check` 會檢查本檔沒有過期）。

**顯示規則：** 器官內的血管、神經要「自己的系統開關（動脈／靜脈／神經）」與「所屬器官開關」都開啟才顯示；經過、沿著器官的血管與神經（主動脈、上下腔靜脈、頭臂靜脈、奇靜脈系統、肺動脈幹、膈神經、迷走神經、喉返神經、交感幹、肋間血管與神經等）不屬任何器官，不會隨器官開關隱藏。

**需人工審核：** 歸屬是解剖判斷，下方「邊界案例」請核對。

## 邊界案例（目前的歸類與理由，請核對）

| 結構 | 目前歸類 | 理由與待你決定 |
| --- | --- | --- |
| 左右肺動脈、肺動脈幹（pulmonary artery、pulmonary trunk） | 經過 | 從心臟走到肺門，在肺門以外不屬於哪一個器官；模型裡的「pulmonary artery」是肺門以外的主幹。肺門以內的葉動脈、肺段動脈才歸肺。請決定肺門處的肺動脈是否也隨肺隱藏 |
| 上、下肺靜脈（superior／inferior pulmonary vein） | 經過 | 同上，從肺門走到左心房；模型裡同名網格有數段（含靠近肺門的分支），目前整條視為經過。肺段、舌段靜脈歸肺 |
| 支氣管動脈、支氣管靜脈 | 肺 | 起自胸主動脈或肋間後動脈，但名稱與走向都是供應支氣管，與肺一起顯示；起始處靠近主動脈的一小段也一起隱藏 |
| 冠狀動脈起始段（trunk of coronary artery） | 心臟 | 起自主動脈竇，主動脈本身仍是經過 |
| 心包膈動脈、心包膈靜脈 | 經過 | 沿心包與膈神經走到橫膈，不是心臟的血管 |
| 肝總動脈、肝固有動脈、肝動脈幹、門靜脈、門靜脈幹、肝前門靜脈 | 經過 | 在肝十二指腸韌帶內，到肝門為止；肝內的葉支、肝段支與肝靜脈歸消化 |
| 腎動脈、腎靜脈 | 經過 | 到腎門為止；腎竇內的肺段以外的節段支（superior／inferior／posterior segmental branch of renal artery 與腎前段動脈）歸泌尿。請決定腎門處是否也隨腎隱藏 |
| 腎上腺靜脈（suprarenal vein）、睪丸動靜脈（testicular）、卵巢血管 | 經過 | 走在後腹膜與腹股溝管，長距離經過；睪丸、卵巢本體的血管模型沒有 |
| 脾動脈、脾靜脈 | 經過 | 沿胰腺走到脾門，沒有脾內分支；若要歸淋巴（脾）請告訴我 |
| 腸繫膜上動脈幹、腸繫膜下靜脈、腸繫膜上靜脈、腹腔動脈幹、胃十二指腸動脈幹 | 經過 | 主幹；由它們發出走向胃、腸、胰的分支（胃、胃網膜、結腸、迴腸、迴結腸、闌尾、盲腸、胰十二指腸、乙狀結腸、直腸上）歸消化 |
| 食道動脈、食道叢 | 消化 | 貼在食道壁上；它們在縱隔，所以「縱隔與心臟」預設開啟消化，仍會顯示 |
| 子宮動脈、子宮靜脈、陰莖背深／淺靜脈 | 生殖 | 只供應子宮／陰莖；陰部內動脈、陰部內靜脈等經過會陰，歸經過 |
| 腦血管（大腦、小腦、胼胝體周圍、脈絡叢、橋腦、丘腦、前後交通動脈等） | 腦（跟「神經系統」開關） | 腦沒有獨立的器官開關，歸神經系統；頸內動脈、椎動脈、基底動脈、眼動脈、脊髓前動脈歸經過。請決定基底動脈是否也隨腦隱藏 |
