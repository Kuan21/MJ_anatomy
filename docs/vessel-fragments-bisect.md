# 血管碎塊追查（2026-11-12）

現象：肩外展 158° 時，動脈與靜脈有幾段變成尖刺鋸齒狀、飛出體外；腹壁血管的末端與分叉處看起來「一節節」。

## 量測方法

`scripts/test-vessel-vertices.mjs`：用檢視器自己的動作解算器擺姿勢（與 `check-stability` 同一套），量每個動脈與靜脈網格（圖譜、示意模型、血管接駁件共 2,007 個）：

- 尖刺：一條邊在擺姿勢後長於 4 mm，而且超過靜止長度的 3 倍；
- 膨脹：擺姿勢後的外框對角線超過靜止時的 2.2 倍；
- 預覽：拖動滑桿時顯示的「只用權重」的形狀，也用同一個尖刺標準；
- 脫離：接駁件的每一條小管，起點離開所屬血管超過 2 mm。

姿勢：肩外展 158°、肩屈曲 73°＋外展 158°、肩屈曲 97°、內旋 48°＋肘屈曲 129°＋腕屈曲 80°、肘屈曲 140°、髖屈曲 120°＋膝屈曲 130°、頭頸屈曲 40°。

## git bisect

- 範圍：`28ac468`（2026-10-26，沒有尖刺）到 `8be492c`（2026-11-09，有尖刺）。更早的版本沒有血管接駁件。
- 每一步都用該版本自己的 `prebuild` 腳本重新產生資料包（到 `prepare-vessel-ends` 為止），再用同一支探測腳本量肩外展 158° 的尖刺頂點數；共 9 步。
- 結果：**第一個出現尖刺的提交是 `b5b68ea`**（2026-10-29，「Shoulder: bind chest-wall axillary branches, chest-wall share of the path field」，屬於 PR #120）。前一個提交 `3a5fa24` 是 0 個尖刺頂點，`b5b68ea` 起是 563 個。

`b5b68ea` 改了兩件事：

1. `pathWeights`：手臂的權重場在肘以上隨「離肱骨軸的距離」由 6 cm 到 12 cm 衰減。血管接駁件（`…-END`，每條血管末端補上的連接管與收尖管）逐個頂點讀這個場，同一圈管壁上相鄰的頂點被分到軀幹與肱骨兩邊，手臂一抬就被扯開。圖譜原本的血管網格沒有尖刺。
2. `prepare-paokao.mjs`：把左右外側乳房動脈（示意模型）綁到手臂。抬手時被拉到約 3 倍長，離母血管（外側胸動脈）31 到 42 mm。

## 「一節節」是另一個提交

腹壁血管末端與分叉處的方角短管，是軀幹上只有 5 個邊的接駁管，自 `28ac468`（PR #53，加入血管接駁件）起就存在；上下肢的在 `32a250d` 改成 12 邊，軀幹的沒有改。把接駁件拿掉重拍，腹壁血管是平滑的。靜止姿勢下膝部 genicular 血管有沒有接駁件看不出差別，沒有重現「一節節」。

**這一項沒有在這個 PR 修**：改成 8 邊後，穩定度檢查多出 16 條「管壁進入骨頭超過 2 mm」（頂點變多後量到更深的點）與 4 條肩部拉伸，資料包也由 4.79 MB 增加到 6.07 MB，需要另開 PR 處理。

## 修正（保留關節動作）

- 接駁件的權重改在每條小管的中心線上讀（`tubeCentres`），同一圈管壁一組權重，不會被橫向剪切；沿管長做三輪平均。
- 所屬血管不跟隨權重場的地方（肩胛分支），整條小管取血管最近頂點的權重。
- 所屬血管由解算器驅動（胸肩峰動脈胸肌支的 follower、外側胸動靜脈的 cable）：小管剛性地跟著解算後的血管表面；遠端若只差 1 cm 以內，沿管長讓一點以維持與下一段相接。
- 拖動時的預覽：上述小管用同一套權重；胸肌支本身在預覽時留在胸壁。
- 外側乳房動脈留在軀幹。

## 其他結構

肌肉與肌腱不是從這兩個提交開始出問題；這次沒有改它們。關掉肌肉後，肩外展 158° 時右胸肩峰動脈胸肌支與它的接駁管會出現在肩外側：它依原設計貼在胸大肌深面，跟著胸大肌走。胸大肌在這個姿勢的位置是否正確，不在這個 PR 的範圍。
