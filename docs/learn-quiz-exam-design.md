# 學習、Quiz、模擬跑考：三個獨立功能的設計（內部文件，不發布到網站）

使用者 2026-11-13 指示。核心發現：先用學習模式學一次再做 Quiz，效果比直接做 Quiz 好，所以把「學習」和「Quiz」分開，再在 Quiz 之上加一個最高難度的「模擬跑考」。三者獨立，但互相連結，共用同一份熟練度資料。保持網站現有淺色風格。網站上不出現任何筆記、共筆或考古題來源。

## 一、頂部入口
「學習 Learn」「Quiz」「模擬跑考」三個獨立入口；模擬跑考標明最高難度。

## 二、Quiz（檢測模式；變回兩個等級）
- 兩個等級：**看名稱找結構**（現第 1 級）、**看結構寫名稱**（現第 3 級）。現第 2 級「學習關卡」移到「學習」。
- 開始前的設定畫面：
  1. 範圍：可多選幾個 section 一次考（例如同時上肢、胸腔、背部），也可細分到某幾個關卡。
  2. 內容類型：骨、肌肉、神經、血管（以及已有的肌腱、韌帶、關節、空間、器官），單選或混合。
  3. 題數：自選（5、10、20、全部或自行輸入）；由已選範圍隨機抽，不重複。
  4. 記住上次的設定，下次預設用回。
- 作答：沒有提示；可中途提早結束，照樣計分，做過的題目計入熟練度。
- 結果頁：錯的題目有「返去學」按鈕，直接跳到包含該結構的學習關卡。

## 三、學習（關卡模式）
- 每個區域（頭頸、上肢、胸腔、背部、腹腔、骨盆與會陰、臀區、下肢）拆成多個細關卡，每關 5 至 8 個結構；次序依「骨 → 肌肉 → 神經 → 血管」，或依局部分區（例：上肢：肩胛區 → 腋窩 → 上臂前區 → 上臂後區 → 肘窩 → 前臂 → 手）。
- 每關三步：
  1. 認識：逐個結構在 3D 模型高亮、鏡頭自動對準，顯示中英名稱與重點（起止點、神經支配、作用或走向；肌肉有動畫時可即場播）。資訊卡沒有的欄位不顯示，不編造。
  2. 練習：在模型上找出剛學的結構，有提示，即時對錯，錯了再顯示一次正確位置。
  3. 過關測驗：短測、沒有提示，達 80% 才解鎖下一關；不夠就提示重溫錯的那幾個。
- 每區有關卡地圖：已過關、進行中、未解鎖；Quiz 經常錯的結構在地圖上標示需要重溫。進度要儲存。
- 先完成上肢與頭頸兩個區域的關卡做示範。

## 四、模擬跑考（獨立模式，最高難度）
- 預設 **50 題、每題 30 秒**（站數與秒數可在開始前調整）。範圍可自由多選 section；選了一個 section，裡面的骨、肌肉、神經、血管、韌帶、肌腱**全部**都納入題池。
- 每站在 3D 模型上插針指住一個結構，要答中英文名稱，**左右要答對**。每站倒數，時間到自動跳下一站，不能回頭；沒有提示、沒有即時對錯，考完才一次出結果。
- **題目順序完全隨機打散**：不會依區域或 section 分段；可能第 1 題上肢、第 22 題心臟、第 3 題足。
- **難度隨機混合**：簡單的（例如斜方肌）和偏僻的（例如手掌的骨間肌這類小結構、相似結構、深層結構）都會出現，且要分清神經、血管、肌腱。
- 結果頁：總分、每站答案對照、用時；錯的題目可一鍵跳到對應關卡重溫。

## 五、三者共用
- 同一份「每個結構」的熟練度資料；學習、Quiz、模擬跑考的表現都會影響熟練度上色與間隔複習。
- 內部儲存鍵維持現有的 `L1`、`L2`、`L3` 命名（只改畫面上的名稱），避免再次搬移使用者已存的資料。

## 六、設計提案（尚待使用者核對）
1. **難度分級：** 用可解釋的規則算每個結構的難度，並允許人工覆寫（寫在人看得懂的設定檔）：結構大小（越小越難）、同組相似名稱的多寡（例如「第二蚓狀肌」與「第三蚓狀肌」）、深淺層、是否左右成對、是否有資訊卡資料。預設抽題比例約 簡單 30%、中等 40%、困難 30%（可調），再依比例隨機。
2. **左右：** 成對結構一律要求答出左或右；中線結構不要求。
3. **跨區域載入：** 每個區域的出題資料是獨立檔案，3D 場景也是分區域的。模擬跑考要在站與站之間切換區域，需要在開始前預先載入所有選到的區域（顯示載入畫面），站與站之間不可因載入而耗掉倒數時間。
4. **3D 插針：** 在結構表面選一個從目前視角可見的點，畫一根細針；不用平面或圓碟。
5. **資料前提：** Quiz 目前只有下肢、上肢、胸腔、背部、心臟、肺。頭頸、腹腔、骨盆與會陰需要補出題資料（骨盆與會陰要等女性結構審完）；臀區在下肢的「臀與髖」段。
6. **資訊卡缺欄位：** 多數結構的起止點、神經支配、作用仍是「尚無資料」，學習的「認識」步驟只顯示有的資料。

## 七、分批（一個 PR 一個主題，均標【需人工審核】）
1. 共用熟練度與設定儲存（不改畫面；含舊資料相容與測試）。
2. 三個入口與頁面架構；Quiz 變回兩個等級，學習關卡搬到「學習」。
3. 區域資料補齊：頭頸 → 腹腔 →（審完後）骨盆與會陰。
4. 學習：關卡地圖、三步驟、80% 解鎖、進度儲存、重溫標示（先上肢、頭頸示範）。
5. Quiz：新設定畫面與結果頁（多選範圍、內容類型、題數、記住設定、提早結束、返去學）。
6. 模擬跑考：插針站、計時、打散順序、難度混合、結果頁。
7. Quiz 小實驗題型（等肌肉動畫）。
