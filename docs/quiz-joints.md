# Quiz 類別「關節 Joints」：規則

關節構造（關節囊、關節盤、半月板、盂唇與關節韌帶）是獨立的題目類別 `joint`（說明：關節囊、關節盤、半月板、盂唇與關節韌帶），可在第一級（找結構）、第二級（引導課程，由同一題庫產生）與第三級（寫名稱）作答。實際題數與每一項排除清單由 `node scripts/test-quiz-joints.mjs --write` 產生在 `docs/quiz-joints-pool.md`。

## 資料來源與部位

- 模型取自主圖譜使用的 `public/models/joints.glb`（Z-Anatomy 的關節軟組織），經 `scripts/lib/joint-quiz-source.mjs` 以與主頁相同的方式註冊到圖譜骨骼上（`createJointAnatomy`，中立姿勢），不另行修改幾何。
- 部位由 `app/quiz/joints.ts` 的 `jointRegion` 決定：四肢依所屬骨骼的圖譜部位；脊柱韌帶（前縱韌帶、後縱韌帶、黃韌帶、棘間韌帶、棘上韌帶、項韌帶）歸背部；肋橫突韌帶、肋頭輻狀韌帶、肋頭關節內韌帶歸胸腔；胸鎖關節的構造歸上肢。
- 區段（section）由既有的 `classifySections` 依部位與位置決定。
- 骨盆（恥骨聯合、恥骨間盤、薦尾聯合、薦髂韌帶、薦結節與薦棘韌帶、髂腰韌帶、角間韌帶）與頭頸（顳顎關節、蝶下頷韌帶、莖突下頷韌帶、莖突舌骨韌帶、環甲與甲狀舌骨韌帶、環咽韌帶）所屬的測驗部位尚未開放，不建立新部位，列為「所屬部位（骨盆、頭頸）尚未開放測驗」，待該部位開放後再納入。

## 分類

- 屬於關節組的構造只屬 `joint`，不會同時屬於 `ligament`（韌帶與筋膜）；`categoryOf` 對 `joint` 系統直接回傳 `joint`，名稱規則不會把它歸到韌帶，也不會把其他系統的構造歸到 `joint`。
- 既有的 `ligament` 類別維持原樣（依名稱收錄圖譜中的韌帶、筋膜等）。

## 可出題的條件

一個關節構造必須同時符合：

1. 有中文名（沿用既有中文名資料，不新增）。
2. 名稱在同部位內唯一（與第二級 `exclusionOf`／`nameCounts` 的規則相同）；同部位內兩個不同構造的中文名相同也視為不唯一。
3. 不是合併關節囊（一個模型涵蓋多個關節，例如掌指、指間、趾間關節囊）。
4. 不是脂肪墊、關節囊繫帶、肋間膜、閉孔膜、方形膜（非關節構造）。
5. 圖譜沒有同名的構造（屬其他系統，例如以細繩呈現的腓側副韌帶），避免同一構造被問兩次。
6. 名稱不帶括號。前、後脛側半月板韌帶的名稱括號內是半月板的名稱（內側／外側），第二級的答案比對會把括號內文字當作別名，導致輸入「Medial meniscus」同時符合半月板與該韌帶，因此不出題。

不能出題的構造一律列在 `docs/quiz-joints-pool.md`，附原因；不會無聲略過。`scripts/test-quiz-joints.mjs` 檢查每個可出題構造有中文名、名稱唯一、有區段、答案卡有資料或明確缺漏清單、不同時屬於 `joint` 與 `ligament`，以及排除清單的每個原因都記載於本檔。

## 排除原因一覽（與 `app/quiz/joints.ts` 的 `JOINT_EXCLUSION_REASONS` 完全相同，由測試核對）

- 不是關節構造（脂肪墊、關節囊繫帶、肋間膜、閉孔膜、方形膜）
- 一個模型涵蓋多個關節的合併關節囊，無法對應單一關節
- 所屬部位（骨盆、頭頸）尚未開放測驗
- 圖譜已有同名構造（屬其他系統），不重複出題
- 名稱括號內是另一構造（半月板）的名稱，輸入答案時會與該構造混淆（前、後脛側半月板韌帶各 2 條）
- 缺中文名
- 名稱與同部位其他關節構造重複

## 答案卡

答案卡只使用專案內已有的資料。目前專案沒有這些構造的所屬關節、附著與功能資料，所以欄位顯示「尚無資料」，並列在 `docs/quiz-card-gaps.md`（由 `node scripts/list-quiz-card-gaps.mjs` 產生）。補充時請在 `app/quiz/card-data.ts` 加入已核對的內容，不推測。

## 左右

成對構造沿用既有的左右處理（名稱以 Left／Right 開頭，中文以左／右開頭）。來源檔中沒有 `.l`／`.r` 後綴的構造：靠近正中線者為不成對（棘間韌帶等），一個偏離正中線的肋頭關節內韌帶則依位置歸入左側。
