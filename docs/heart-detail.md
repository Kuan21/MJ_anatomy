# 心臟詳細模式與心臟 Quiz

## 放在哪裡
- **圖譜**：左側圖層「Organs → Heart」那一列多了「詳細」按鈕，進入 `#/organ/heart`。這是獨立頁面，不改動主圖譜的場景與載入流程；回到圖譜時一切如舊。
- **Quiz**：首頁「器官」區新增「心臟」（`#/quiz/heart`），與其他 Quiz 共用同一套引擎。
- 選擇獨立頁面而非直接塞進主場景，是因為心臟詳細模型有 28.5 萬個三角面；放在主場景會拖慢全站載入與拖動。現在只有進入詳細模式或心臟 Quiz 才下載（圖譜首頁載入時 0 個心臟套件請求）。

## 模型來源與授權
- Z-Anatomy 的 cardiovascular 匯出（`nqwrc/3d-anatomy` 固定 commit `8ca3b742…`，檔案 sha256 已固定在 `scripts/heart-parts.json`），內容為 BodyParts3D 的衍生作品：**CC BY-SA 4.0（Z-Anatomy）＋CC BY-SA 2.1 Japan（BodyParts3D）**。
- 同一個 repo 另外混有 Kidney（CC BY-NC 4.0）、內耳（CC BY-NC-SA 4.0）、Brainder／白質（授權未註明），**一件都沒有使用**；只解碼 `heart-parts.json` 列出的 38 個心臟相關節點，測試會檢查名單不含這些件。
- 歸屬與修改說明：`public/models/heart/ATTRIBUTION.md`。

## 內容（38 件）
心腔 4（左右心房、左右心室）、乳頭肌 4、瓣膜 9（右房室瓣下尖／中隔尖、左房室瓣後尖、主動脈瓣三瓣、肺動脈瓣三瓣）、冠狀動脈 6、心臟靜脈 5、相連大血管 10。每件有英文名、臺灣用語中文名與簡短說明。

**腱索**：腱索不是獨立的件，而是包含在房室瓣瓣葉的網格內（逐件渲染確認：左房室瓣後尖與右房室瓣兩尖瓣都帶有腱索狀的條索）。所以腱索會跟著瓣葉一起顯示、選取，但**不能單獨作為答案**。

**模型沒有的構造**（資料卡與頁面都已註明，Quiz 不出題）：界嵴、梳狀肌、卵圓窩、節制索、傳導系統（竇房結、房室結、希氏束、束支），以及二尖瓣前尖、三尖瓣前尖、左心室前乳頭肌。要補的話需要另找授權明確的來源。

## 與圖譜原有心臟的關係
- 圖譜原有的「Heart」層是 BodyParts3D 4.0 的心腔空腔、心壁與瓣葉（18 件，低面數）。詳細模式使用 Z-Anatomy 的版本，兩者座標系相同，但心臟中心相距約 14 mm（兩個版本的心臟形狀略有不同）；因為詳細模式是單獨檢視，沒有疊合，所以不會互相穿插。
- 修正：原有「Heart」層混入了 5 個腦室（第三、第四、左右側腦室、室間孔），它們屬於神經系統，已改歸入神經系統，Heart 層現在只有 18 件心臟。

## 詳細模式功能
- 三種切面（冠狀、矢狀、橫斷）加位置滑桿與反向；心腔半透明；各組構造顯示／隱藏；視角（前、後、左、右、上）。
- 懸停以淺薄荷綠標示，點選以深綠色加外框標示（與圖譜一致）；清單與模型雙向選取，名稱與說明顯示在右側最上方。

## 效能
- 套件 10 個，壓縮後共 3.02 MB（原始 6.0 MB），低於每個器官 5 MB 的上限；內容以內容雜湊命名，可長期快取。
- 本機（無 GPU 的 SwiftShader）從開啟頁面到全部載入完成約 2.2 秒；圖譜首頁載入時完全不下載心臟套件，所以主圖譜的載入時間與拖動效能不受影響。
- 未量度真機 FPS（沒有 GPU 或 iPad）。

## 驗證
`node scripts/test-heart-detail.mjs`（已包含在 `npm run check` 與 `check:quiz`）：固定來源的 sha256、只含允許清單、幾何完整（座標有限、索引有效、法線為單位向量）、套件內容雜湊、與圖譜心臟的距離、Heart 層不含腦室、路由與入口。心臟 Quiz 由 `test-region-quiz.mjs` 與 `test-region-quiz-flow.mjs` 涵蓋（逐件與來源位元組比對）。
