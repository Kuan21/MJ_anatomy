# 上肢關節動作與顯示問題修正（穩定期 S2-A 的一部分）

對應使用者回報的七張截圖（肩屈曲 97°；肩屈曲 73° ＋ 外展 158°；肩內旋 48° ＋ 肘屈曲 129° ＋ 腕屈曲 80°；資訊卡與介面）。
本文只寫原因、做法與驗證方法；數值以 `node scripts/audit-limb-pose.mjs` 與 `node scripts/test-limb-tears.mjs` 為準。

## 檢查方法（新增）

- `scripts/audit-limb-pose.mjs`：用網站自己的求解器擺出姿勢（與 `check-stability.mjs` 同一套），逐個結構量四件事。
  - **撕裂（tear）**：一條邊擺姿勢後長於 15 mm，而且超過原長 3 倍（看得見的缺口或尖刺；原長 0.1 mm 變 3 mm 不算）。
  - **拉長（stretch）**：邊超過原長 2 倍且長於 3 mm（穩定期檢查原有的標準）。
  - **離骨（detached）**：靜止時貼著會動骨骼的血管、神經、肌腱、韌帶，擺姿勢後離該骨超過 15 mm。
  - **端段偏離（seam）**：血管端段（`-END`）與它所延續的血管，在靜止時重疊的點，擺姿勢後平均距離（上限 8 mm）。
- `--set=reported`（三組回報姿勢）、`--set=sweep`（每個滑桿的最小值與最大值）。
- `scripts/test-limb-tears.mjs` 把三組回報姿勢變成測試：不可有撕裂（除了下面「限制」列出的幾條，並設上限）、任何邊不可長於 50 mm、端段不可離開血管。已併入 `npm run check` 與 `npm run check:motion`。

## 原因與修正

| 問題 | 原因 | 修正 |
| --- | --- | --- |
| 動脈碎片飛出、紅色鋸齒尖刺（外展 158°） | 血管端段（`-END`）照抄所屬血管的皮膚權重，但胸廓纜索與肌肉扇形血管不是只靠權重變形。 | 本 PR 原先的 `alignEndPiece` / `endOf` 做法已捨棄，改以 main 的 #270 版本為準（原因、追查與回歸測試見 `docs/vessel-fragments-bisect.md` 與 `scripts/test-vessel-vertices.mjs`）。本 PR 的 `test-limb-tears.mjs` 仍檢查三組回報姿勢下的撕裂與端段偏離。 |
| 韌帶被撕開（肋鎖韌帶拉長 18 倍、肩胛上橫韌帶 12 倍） | 這兩條韌帶用了盂肱關節的權重規則（肩胛骨與肱骨各半）。 | 依名稱分別處理：肩胛上、下橫韌帶只跟肩胛骨；肋鎖韌帶由胸廓端漸變到鎖骨端。 |
| 肋間膜浮在上肢區、沒有肋骨 | 關節軟組織（Z-Anatomy）依「最近的骨」找錨點，上方的肋間膜落到鎖骨或肩胛骨上，被當成上肢結構並被手臂的骨架帶動。 | 胸壁組織（肋間內／外膜、肋橫突韌帶、肋頭韌帶）的候選錨點限於肋骨、胸骨、胸椎（`joint-anatomy.ts`）。 |
| 肩胛背動脈區域寫成「上臂」 | `anatomicalSubregion` 的高度帶（1.37 m 以下一律上臂）排在肩帶名稱判斷之前。 | 名稱明確屬於肩帶時優先（`mj-part-regions.ts`）；資訊卡改寫「肩胛區／背部」。 |

## 區域分類清單（同類錯誤）

已修正（Region 欄原本寫「arm 上臂」，現為「shoulder girdle 肩帶」；背側者寫「scapular region / back 肩胛區／背部」）：左右各 21 個，共 42 個：胸大肌三部、胸小肌、前鋸肌、三角肌三部、岡下肌、肩胛下肌、大圓肌、小圓肌、斜方肌升部、大菱形肌、肩胛骨、腋靜脈、旋肩胛動脈與靜脈、肩胛背動脈、肩胛下動脈、胸肩峰動脈胸肌支。
已修正（錨點）：外／內肋間膜（左右共 4 片）原本可能錨在鎖骨或肩胛骨而被列入上肢；現錨在肋骨。
仍然可疑、這次沒有改（需要使用者決定）：
- 後胸鎖韌帶錨在第一肋、歸「軀幹」，但前胸鎖韌帶、胸鎖關節囊與關節盤錨在鎖骨、歸「上肢」：同一個關節分在兩個區域。
- 骶結節韌帶、髂腰韌帶、閉孔膜、恥骨聯合與恥骨上下韌帶、恥骨間盤錨在髖骨，歸「下肢」；解剖上屬骨盆。
- 圖譜本體的其他 2,190 個結構以名稱與位置交叉核對，未再發現不一致（腦的 brachium、腦血管的 brachiocephalic 是名稱相似而非肢體結構）。
肩胛背動脈來源：資訊卡寫出兩種變異（鎖骨下動脈第三段，有時第二段；或頸橫動脈深支）。**資料夾內沒有 115-1 跑考摘要的內容，這一條沒有逐字對照，請使用者核對**。

## 限制（沒有做到的，不隱瞞）

- 跨過腋窩的長血管與神經叢（腋動脈、腋靜脈、臂神經叢各幹、胸長神經等）在手臂抬高到 150° 以上時，與肩胛骨與鎖骨的距離仍會拉開 20–60 mm（`detached`，見 `docs/stability-baseline.md`）。權重場是位置的函數，同一位置的兩個網格必須得到同一個權重，否則接頭會撕開；要讓整條血管平均分攤，需要血管樹的拓樸資料，這次沒有做。
- 外側乳房動脈（約 6 cm，起點在腋窩、末端在胸壁）在外展 158° 時仍有一段被拉長最多 8 倍（單條邊 4 mm → 31 mm）。曾試過把權重沿血管平均分攤（最大 3.7 倍），但它與胸肩峰動脈胸肌支的接頭會張開 25–60 mm（`test-vessel-motion.mjs` 判為新的斷開），所以沒有採用。
- 背闊肌（約 24% 的三角形超過 2 倍）、大圓肌、喙肱肌、前肘肌、旋後肌仍有輕微拉長，原有已知清單的狀況，沒有惡化。
- 肩外展 180° 時鎖骨總旋轉約 66°（教科書上鎖骨抬高約 30–45°，另加軸向旋轉與後縮），由肩胛骨貼胸廓的接觸求解決定，這次沒有動它。
- 在容器裡只有 SwiftShader 軟體繪圖：沒有在真機（iPad、手機）確認幀率與觸控；螢幕截圖是 3D 畫面，但仍需使用者核對解剖位置。
