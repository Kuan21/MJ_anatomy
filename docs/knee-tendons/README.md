# Knee tendons and ligaments (schematic)

Quadriceps tendon (tapered band from the four heads to the patellar base), patellar ligament,
medial and lateral patellar retinacula and the iliotibial tract (Thigh) are schematic models
built in `scripts/paokao-structures/knee.mjs`. Tendons use the card fields Origin / Insertion / Function.

Screenshots are offline renders (`scripts/render-preview.mjs`): `conn-*` = bones + connective tissue,
`connmus-*` = plus muscles. Known limitation: retinacula are deliberately thin sheets.
